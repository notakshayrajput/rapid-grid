02 / THE THINKING BEHIND IT

Built for data that refuses to fit.

rapid-grid keeps collection state, geometry, and DOM rendering separate. You can change one layer without bringing a framework or a heavy table stack along for the ride.

01
⊞

Render the window

Rows and columns are indexed by pixel offsets. The DOM contains the visible window and a small directional buffer, even when the dataset is enormous.

02
↻

Reuse the cells

Scrolling recycles positioned elements. Formatting and editing hooks work on those cells, so custom controls stay close to the data they represent.

03
⌘

Own your stack

The core is plain TypeScript and browser DOM. Use it directly or mount it from React, Vue, Angular, Svelte, or a Web Component.
